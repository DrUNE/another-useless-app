# 0009. Типизированный IPC через tauri-specta

Статус: принято (2026-10-31)

## Контекст

В Tauri интерфейс (JS в WebView) вызывает Rust через IPC: `invoke("save_url", { url, path })`.
Имя команды, имена и типы аргументов, форма ответа и ошибок — всё это строки и `any` на стороне TS.
Опечатка в `"save_url"` или смена поля в Rust обнаруживаются только в рантайме. То же было с WASM-границей,
которую [ADR-0008](0008-wasm-boundary.md) решает так: форма контракта описана в Rust, TS-типы генерируются.

## Решение

Команды описываются в Rust, а TS-привязки **генерируются** библиотекой `tauri-specta`:

- команды помечены `#[tauri::command]` и `#[specta::specta]`, список собран в одном месте
  (`specta_builder()` в `apps/native/src-tauri/src/lib.rs`);
- из этого списка строятся и обработчик IPC, и файл `apps/native/src/bindings.ts` с функциями
  `commands.saveUrl(url, path)` и типами `SaveReport`, `CommandError`;
- ошибки — перечисление с тегом (`CommandError` с полем `kind`), а не строка. В TS это размеченное
  объединение, и `switch (e.kind)` проверяется компилятором на полноту (`apps/native/src/core.ts`);
- привязки **коммитятся**, а тест `bindings_are_up_to_date` сравнивает их с тем, что генерирует Rust, и
  падает при расхождении. Обновить: `bun run update:bindings`;
- версии `tauri-specta`, `specta` закреплены через `=`: это release candidate, и обновление между rc
  ломает API.

## Альтернативы

- **Ручной `invoke` с TS-типами.** Ничего не добавляет к сборке, но типы пишутся дважды и расходятся молча.
- **`ts-rs` или `specta` без `tauri-specta`.** Генерируют типы данных, но не функции вызова: имена команд
  и аргументов остались бы строками.
- **Не коммитить `bindings.ts`, генерировать при сборке** (как `pkg` для WASM в ADR-0008). Привязки получаются
  запуском Rust-кода, поэтому `bun run typecheck` потребовал бы Rust и WebKit. Коммит файла с проверкой
  актуальности сохраняет быстрый typecheck без Rust.
- **Локальный HTTP или WebSocket сервер вместо IPC.** Открывает порт на машине пользователя и теряет модель
  разрешений Tauri. Лишняя поверхность атаки.

## Последствия

- (+) Переименование команды или поля в Rust ломает сборку TS, а не работу приложения.
- (+) Ошибки типизированы: UI различает «нет сети» и «недопустимый путь» по `kind`.
- (+) Тест на актуальность привязок ловит забытое обновление в CI.
- (−) `tauri-specta` v2 остаётся в статусе rc. Закрепление версий снижает риск, но обновление может потребовать правок.
- (−) Ограничения specta: `u64`/`usize` не выводятся без BigInt, поэтому `bytes` — `u32` (с насыщением на 4 ГБ).
- (−) Один и тот же `SaveReport` описан в трёх местах: ядро, WASM-привязка и Tauri-команда. Единый TS-интерфейс
  сервиса (#5) уберёт дублирование на стороне UI, но не на стороне Rust.
- (−) Привязки — сгенерированный файл в репозитории: правки руками пропадают, а диффы шумят при смене форматирования генератора.
