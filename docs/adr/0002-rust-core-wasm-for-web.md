# 0002. Ядро на Rust, web через WASM

Статус: принято (2026-10-31)

## Контекст

Приложение должно существовать в четырёх видах, собираемых отдельно: CLI, web, desktop и mobile
(Tauri 2). Нужен **общий код** между ними, а не четыре копии логики. Основная цель проекта —
изучить практики кроссплатформенной разработки, включая то, как одно ядро живёт в нативном
коде и в браузере.

Tauri 2 по устройству состоит из Rust-бэкенда и веб-интерфейса, поэтому у Rust-кода в проекте
в любом случае есть место (`src-tauri`).

## Решение

Платформо-независимое ядро пишется на Rust (крейт `app-core`).

- **CLI** (`crates/cli`) и **Tauri** (`src-tauri`) подключают его как обычную библиотеку.
- **Web** получает то же ядро, собранное в WASM (`wasm32-unknown-unknown`) через `wasm-bindgen`.
- Интерфейс (Solid, Tailwind) остаётся на TypeScript и обращается к ядру через единый
  TS-интерфейс сервиса: в вебе его реализует WASM, в Tauri IPC (будущий ADR).

## Альтернативы

- **Ядро на TypeScript.** Работает везде, где есть JS: web, Tauri WebView, Node/Bun для CLI.
  Одна кодовая база, нет WASM-сборки и IPC, проще отладка. Для приложения с одним UI это
  объективно проще. Отклонено: CLI и Tauri-бэкенд не смогли бы делить код с Rust-стороной,
  и теряется основная учебная часть (одно ядро в нативе и в WASM).
- **Rust-ядро без web.** Убирает WASM, но web — одна из обязательных целей.
- **Два ядра (Rust и TS) с общим контрактом.** Дублирование логики и риск расхождений.

## Последствия

- (+) Один код логики для CLI, desktop, mobile и web.
- (+) Типобезопасность и производительность Rust там, где это нужно.
- (−) Входной порог: Rust и WASM сложнее TS-стека. Автор проекта знает TS лучше, чем Rust,
  поэтому ожидаются дополнительные затраты времени.
- (−) Два пути к ядру из UI: WASM в вебе и IPC в Tauri. Нужен общий TS-интерфейс (шаг 5 дорожной карты).
- (−) В WASM нет файловой системы и сокетов: ввод-вывод нужно выводить из ядра в порты
  ([ADR-0003](0003-ports-and-adapters.md)).
- (−) Ограничение на зависимости ядра: всё, что не собирается под `wasm32`, в `app-core` нельзя.
- Не проверено: сборка `app-core` под `wasm32-unknown-unknown` пока не запускалась (таргет не
  установлен). Проверим на шаге 3.
