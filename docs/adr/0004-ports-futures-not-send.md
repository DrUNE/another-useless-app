# 0004. Futures в портах без требования `Send`

Статус: принято (2026-10-31)

## Контекст

Порты ([ADR-0003](0003-ports-and-adapters.md)) асинхронные. В Rust trait может содержать
`async fn`, но есть тонкость: возвращаемый future либо обязан быть `Send` (его можно перемещать между
потоками), либо нет.

- Нативные рантаймы вроде многопоточного tokio требуют `Send` для задач, запускаемых через `tokio::spawn`.
- В WASM код выполняется в одном потоке, а значения из JS (`JsValue`, `Promise`) не `Send`.
  Адаптер, который ждёт JS-промис, не может вернуть `Send`-future.

Если требовать `Send` в trait, web-адаптеры невозможно написать. Если не требовать, возникает
вопрос про нативный код.

## Решение

В trait `Fs` и `Http` используем обычный `async fn` **без** требования `Send`
(`#![allow(async_fn_in_trait)]` в `ports.rs` подавляет предупреждение компилятора об этом).

Нативный код при этом остаётся пригодным для многопоточности: когда `save_url` вызывается
с конкретными типами (`NativeHttp`, `NativeFs`), компилятор выводит, что итоговый future `Send`, так как
`Send` — автоматический trait, и «просачивается» через конкретные типы. Для TS-разработчика это
необычно: свойство типа выводится из содержимого, без явной аннотации.

## Альтернативы

- **Требовать `Send` в trait (`-> impl Future + Send`).** Нативные вызовы работают в любой
  конфигурации, но web-адаптеры написать нельзя.
- **Два варианта trait через крейт `trait_variant`** (с `Send` и без). Рабочий путь, но лишняя
  зависимость и дублирование; пока нет задачи, которая ломается без него.
- **Однопоточный рантайм везде.** Лишает нативный код преимуществ многопоточности.

## Последствия

- (+) Один trait подходит и нативу, и WASM.
- (+) В конкретных вызовах (CLI, Tauri-команды) `Send` выводится сам.
- (−) В **обобщённом** коде (`fn run<F: Fs>(fs: F)`) `Send` для future неизвестен, и такой future
  нельзя отправить в `tokio::spawn`. Нужно либо вызывать с конкретным типом, либо вводить
  `trait_variant`.
- (−) Ошибка компилятора при нарушении бывает длинной и непонятной; придётся к ней привыкнуть.
- Не проверено на практике: поведение со Tauri-командами будет видно на шаге 4.
